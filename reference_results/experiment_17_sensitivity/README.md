# Experiment 17 strict official-cMHN sensitivity

This directory freezes the patient-grouped out-of-fold official-cMHN
sensitivity analysis produced during the Phase-0 re-audit. It changes both the
backbone estimator and the evaluable-pair population relative to the selected
legacy Experiment 17 analysis. It is therefore reported as a strict
sensitivity, not silently substituted for the selected external-consistency
estimand.

The mixed directions, including the negative CRC result, must be disclosed in
the supplement. These results limit the longitudinal claim to cautious external
consistency under the selected full-cohort fallback backbone.
